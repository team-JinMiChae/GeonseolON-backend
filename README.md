# GeonseolON-backend

# 기능
- 안전 수칙 API  
  - 사용자 질문에 따라 관련 사고 사례 및 예방 수칙을 1:1 대화형 AI로 제공
- 날씨 API  
  - 사용자 위치 기반 실시간 기상 데이터 제공  
  - AI가 날씨에 따른 주의 사항 안내
- 안전 기관 API  
  - 사용자 위치 기반 근처 안전 교육기관 및 센터 정보 제공
- 기관 관리 백엔드 API  
  - 기관 정보 등록, 조회, 수정, 삭제
  - 데이터베이스 연동 및 엔티티 관리
- RESTful API 설계 및 구현
- Docker/Kubernetes 배포 환경 지원  
  - Docker Compose 및 K8s yaml로 컨테이너/클러스터 배포 가능

# 성과 및 최적화 작업
- LEG(Embedding 기반) 통한 안전 수칙 AI
  - 사고 공공데이터를 벡터 임베딩하여 DB에 저장 및 관리
  - 유사도 분석을 통해 사고 사례 자동 분류 및 AI 기반 정리
  - 사고 유형별로 AI가 관련 안전 수칙 및 예방 가이드 제공
  - 사용자 질문에 따라 맞춤형 사고 사례 및 예방 수칙 실시간 제공
  - 지속적 데이터 업데이트 및 AI 모델 고도화로 정확도 향상
- 날씨 API 최적화
  - 기상청 API를 활용한 실시간 날씨 정보 제공
  - 응답값 캐싱 및 페이징 처리로 API 호출 효율화
  - AI가 날씨에 따른 주의 사항 안내 및 사용자 위치 기반 정보 제공
- DB 쿼리 최적화 및 인덱스 적용으로 응답 속도 개선
- 비동기 처리 및 예외 핸들링 강화
- 코드 리팩토링 및 테스트 코드 추가로 유지보수성 향상
- Docker/Kubernetes 환경에서 안정적 서비스 운영
